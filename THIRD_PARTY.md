# Лицензии и происхождение файлов

Репозиторий — набор данных для сборки прошивок STM32: файлы скачиваются в проект
командой `download_one()` из `stm32_cmake_base`. Ниже — кому принадлежит каждая
часть и под какой лицензией она распространяется.

| Путь | Автор | Лицензия |
|---|---|---|
| `startup_c/startup_common.c` | VarvaR | MIT (`LICENSE`) |
| `linker/*.ld.in` | VarvaR | MIT (`LICENSE`) |
| `cmake/*` (map-таблицы, шаблоны `.h.in`) | VarvaR | MIT (`LICENSE`) |
| `flash_sectors.py`, `README.md` | VarvaR | MIT (`LICENSE`) |
| `startup_c/*/vector_*.c` | VarvaR; имена обработчиков — по документации ST | MIT, с оговоркой ниже |
| `Device/**` (заголовки устройств, `system_*.c/.h`) | STMicroelectronics | Apache-2.0 (`LICENSES/Apache-2.0.txt`) |
| `SVD/**` | STMicroelectronics | Apache-2.0 (`LICENSES/Apache-2.0.txt`), см. ниже |

## Файлы ST (`Device/`, `SVD/`)

Файлы скопированы из репозиториев STMicroelectronics без изменений. Заголовки
`Device/**` содержат фразу «This software is licensed under terms that can be
found in the LICENSE file»; в официальных репозиториях `cmsis_device_*`
этот файл — **Apache-2.0**. Проверено по репозиториям ST для всех семейств,
что есть в `Device/`: F0, F1, F2, F3, F4, F7, G0, G4, H7, L0, L1 (у F1 и F2 файл
называется `License.md`). Заголовки с авторскими правами ST должны сохраняться
при любом копировании.

`SVD/**`: 94 из 103 файлов содержат `SPDX-License-Identifier: Apache-2.0`.

**Девять файлов** — `SVD/STM32F0xx/STM32F0x0.svd`, `STM32F0x1.svd`,
`STM32F0x2.svd`, `STM32F0x8.svd` и `SVD/STM32F1xx/STM32F100.svd`, `STM32F101.svd`,
`STM32F102.svd`, `STM32F103.svd`, `STM32F107.svd` — это более старые SVD от ST,
в самих файлах заголовка с лицензией нет. Что известно об их статусе:

- архив [modm-io/cmsis-svd-stm32](https://github.com/modm-io/cmsis-svd-stm32)
  (файлы ST «с сайта ST», изменены только окончания строк и пробелы) объявляет
  **все** свои SVD, включая эти девять, лицензированными как **Apache-2.0**
  (`LICENSE.md`, README); версии файлов в нём те же (F0x0 v1.2, F103 v1.1);
- более новые SVD ST в этом же каталоге (F4, G0, G4, H7 и др.) несут явный
  заголовок Apache-2.0 от ST — т.е. намерение ST лицензировать SVD этой лицензией
  подтверждается;
- самостоятельного подтверждения на стороне ST для этих девяти файлов нет.

Вывод: распространяются как Apache-2.0 на основании заявления modm-io и
лицензирования остальных SVD ST; строго подтверждённым этот статус не является.
Если нужна полная определённость — заменить файлы на версии из официального
пакета ST или убрать их (SVD нужен только отладчику).

## Таблицы векторов (`startup_c/*/vector_*.c`)

Файл — это перечень имён обработчиков прерываний конкретной микросхемы в
порядке, заданном документацией и CMSIS. Первоначально перечни были получены
разбором стартап-файлов `startup_*.s` из репозиториев ST (они распространяются
на тех же условиях, что и `Device/`, Apache-2.0); оригинальные `.s` в
репозиторий больше не входят. Имена обработчиков — общепринятые (CMSIS), код
таблиц и `startup_common.c` написан автором.

## Что убрано

Из форка удалён код апстрима STM32-base (GPL-3): каталог `startup/`, README,
CONTRIBUTING и скрипты конвертации. Начиная с этой версии GPL-3 в дереве
репозитория нет. В истории git старые версии остаются под GPL-3 — эта
лицензия действует для тех, кто получил именно те версии.
